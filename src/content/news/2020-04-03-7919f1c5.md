祁阳一中2020年春季高三即将开学，现就收费有关事项说明如下：

  

 **一、缴费方式：**通过关注“祁阳一中”微信公众号，在公众号首页下面菜单栏点击“教育缴费”按缴费步骤缴费。（详细缴费步骤已发在各班家长群和“祁阳一中”微信公众号里，请家长们查看）

**二、缴费时间：**2020年4月4日07：00时-2020年4月5日22：00时止，请务必在规定时间内缴费，其他时间段无法缴费。

 

**三、缴费标准****(****合计****)****如下表：**

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 年级 | 类别 | 合计 | 班次 | 建档立卡贫困学生 |
| 高三 | （文科）通学生 | 1413.3 | C633-637 | 16 |
| （文科）寄宿生 | 3293.3 | 1896 |
| （理科）通学生 | 1436 | C618-632 | 16 |
| （理科）寄宿生 | 3316 | 1896 |

**注：学校财务室已经将每位同学的具体收费金额上传到微信公众号里了，收费金额已确定不能修改，家长缴费时只要核对班次、姓名、身份证号是否正确就可以缴费了，如对缴费金额有疑问，拨打3239554电话咨询或先缴费，待到校后再办理相关手续。****四、**微信缴费成功后，学校财务室会统一开出学费发票，待开学到校后一周内发放给学生。  
**五、**学校财务室开学当天会提供已缴费学生花名册给相关处室，方便学生直接办理开餐、领书手续。  
**六、**请各班班主任通知学生必须在规定时间内缴费，并要求学生或家长缴费成功后马上截图给班主任，班主任要及时通知未缴费同学在规定时间内通过微信公众号缴费。  
**七、**温馨提示：由于微信支付金额受限，请家长最好在4月4日前保证微信账户上有足够的余额或绑定有足够余额的银行卡再缴费。
