# 测试与截图

## 命令

| 命令               | 作用                                     |
| ------------------ | ---------------------------------------- |
| `pnpm check`       | Astro 类型 / 模板检查                    |
| `pnpm build`       | 生产构建                                 |
| `pnpm preview`     | 预览构建产物（默认 4321）                |
| `pnpm screenshots` | 用本机 Chrome 生成桌面 / 手机 / 深色截图 |
| `pnpm og`          | 重新生成默认 OG 图                       |

## 截图脚本

`scripts/screenshots.mjs`：

- 使用 Playwright + 本机 Chrome（`channel: "chrome"`），不需要下载浏览器；
- 输出到 `.screenshots/`（已加入 `.gitignore`）；
- 覆盖：
  - 首页 Hero、简介、历史、新闻、联系（浅色 / 深色）；
  - 关于、产品、新闻、联系、文章、404；
  - 手机首页、产品、文章；
  - 手机菜单；
  - 新闻分类筛选；
  - 主题切换；
- 收集 `pageerror` 与 console error，并在末尾输出；
- 滚动到区块时使用 `offsetTop`，再触发 reveal，避免 `scrollIntoView` 只滚一半。

运行：

```bash
pnpm build
pnpm preview
# 另开终端
pnpm screenshots
```

## 已知限制

- 没有单元测试框架；逻辑正确性依赖类型检查、构建、截图与手动验收。
- 没有自动化视觉回归基线；截图用于人工比对。
- 图片没有自动 `srcset`。
- Slogan 一言 API 需要浏览器网络；失败时静默回退到本地句子。
- 站内品牌与首页示例文案仍是模板内容；产品卡片 / 详情页文案来自星籁浮屿官网。
- 产品 logo 与二次元背景均为测试素材，上线前请替换或确认授权。
- 源站的游戏描述、角色描述与制作人员仍是占位文本，页面如实展示，不补写虚构内容。

## 可改进方向

1. 用 Playwright 写断言（导航切换、主题持久化、筛选数量）。
2. 把截图纳入 CI artifact，或接入视觉回归服务。
3. 增加 Lighthouse CI / Web Vitals 基线。
4. 增加无障碍扫描（axe-core）。
5. 增加断链检查（构建后遍历 HTML）。
